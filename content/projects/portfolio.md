# Personal portfolio

This site is an editable home for my projects, posts, and general pages.

## Content-first structure

Pages, posts, and projects are Markdown files with a small set of fields. Site-wide text and links live in one settings file.

## Keeping it current

The content-first structure keeps writing and project notes easy to extend while the visual system stays consistent.
